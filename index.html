Community Detection Visualizer documentation¶

This project finds and draws communities (tightly knit groups) in real-world networks. It compares a from-scratch Girvan–Newman implementation with the Louvain method on three datasets: Zachary’s Karate Club, the Dolphin Social Network, and a Facebook ego network from Stanford SNAP.

Source code: https://github.com/ksavva77/Community-Detection-Visualizer

Run everything with python src/main.py.

Girvan–Newman (from scratch)¶

Girvan–Newman community detection, implemented from scratch.

The Girvan–Newman algorithm finds communities by removing edges rather than grouping nodes. Edges that connect two communities carry many shortest paths between them (high edge betweenness), so removing them one at a time slowly splits the graph apart:

  1. Compute the edge betweenness of every edge.

  2. Remove the edge with the highest betweenness.

  3. Recompute betweenness and repeat until no edges are left.

Each time the graph splits into more pieces, the pieces form a candidate partition. The partition with the highest modularity (Q) is returned as the answer.

Everything in this module (breadth-first search, connected components, Brandes’ edge-betweenness algorithm and modularity) is written with plain Python data structures. NetworkX is used only to read the input graph. The one speed-up: after an edge is removed, betweenness is recomputed only for the component that contained it, because shortest paths in every other component are unchanged.

girvan_newman.edge_betweenness(adjacency, nodes=None)¶

Compute edge betweenness with Brandes’ algorithm.

The edge betweenness of an edge is the number of shortest paths, between all pairs of nodes, that pass through it. When there are several equally short paths between two nodes, each one counts as a fraction. For an unweighted graph, Brandes’ algorithm runs one breadth-first search per source node, in O(nm) time overall.

Parameters:

  • adjacency (dict of node to set) – Adjacency dictionary.

  • nodes (iterable, optional) – Only use these nodes as sources. Pass one connected component to score just that component’s edges. Defaults to every node.

Returns:

Maps each edge key (see edge_key()) to its betweenness. Each unordered pair of nodes is counted once.

Return type:

dict of tuple to float

girvan_newman.modularity(adjacency, communities)¶

Compute the modularity (Q) of a partition, from scratch.

Modularity compares the number of edges inside each community with the number expected if the edges were placed at random:

Q = sum over communities c of [ L_c / m  -  (d_c / 2m)^2 ]

where m is the total number of edges, L_c is the number of edges inside community c, and d_c is the sum of the degrees of its nodes. Q is close to 0 for a random split. Values above about 0.3 mean the graph has clear community structure.

Parameters:

  • adjacency (dict of node to set) – Adjacency dictionary of the original graph (before any edges were removed).

  • communities (iterable of set) – The partition: every node in exactly one set.

Returns:

The modularity, between -0.5 and 1.

Return type:

float

Datasets and raw graphs¶

Community Detection Visualizer: dataset loading and raw-graph visualization.

This module is the first milestone of the CSCI 310 final project Community Detection and Visualization in Real-World Networks. It loads three real-world networks, prints a summary table of their basic properties, and draws each network before any community detection is run, so the later results have a baseline to compare against.

The three datasets are:

  • Zachary’s Karate Club, built into NetworkX (34 nodes, 78 edges).

  • Dolphin Social Network, from the Network Repository (62 nodes, 159 edges).

  • Facebook ego network, one person’s friend circle taken from the Stanford SNAP ego-Facebook dataset.

The dolphin and Facebook files are downloaded the first time they are needed and kept in the data/ folder, so later runs work offline.

Run the module from the repository root:

python src/community_detection.py

Each node has a club attribute ("Mr. Hi" or "Officer") recording which side the member joined after the club split. This real split is the ground truth used later to measure how accurate the detected communities are.

NetworkX stores a weight on each edge (how many activities two members shared). The weights are removed so that every dataset is treated as unweighted, the same way Girvan–Newman treats it.

Comparison and visualization¶

Compare Girvan–Newman with Louvain and draw the results.

This module runs both algorithms on every dataset and produces the project’s outputs:

  • a console table of communities, modularity (Q), runtime and the top bridge edges for each dataset;

  • color-coded community drawings next to the raw graph;

  • modularity curves showing how Q changes as Girvan–Newman removes edges;

  • a runtime-scaling chart across several Facebook ego networks;

  • an accuracy check on the Karate Club against the club’s real split.
