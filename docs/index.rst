Community Detection Visualizer documentation
============================================

This project finds and draws communities (tightly knit groups) in
real-world networks. It compares a from-scratch Girvan–Newman
implementation against the Louvain method on three datasets: Zachary's
Karate Club, the Dolphin Social Network, and a Facebook ego network from
Stanford SNAP.

Source code: https://github.com/ksavva77/Community-Detection-Visualizer
